# 游戏服务器带宽：按人数算出要多少M上行，再看雨云游戏云 10M/15M/20M 三档怎么选

问"带宽够不够"的人，多半已经踩过一次坑了：CPU 堆得不低，内存也留了余量，结果晚上八点一开黑就卡——TPS 往下掉，玩家操作有延迟感，重进一下能缓十分钟，然后继续卡。

带宽确实是原因之一，但"越大越好"解决不了这个问题。更值得先弄清楚的是三件事：游戏服吃的是哪一头、按什么公式估、以及共享和独享差在哪。

## 先纠正一个最容易搞反的方向：游戏服吃上行

从服务器视角看，带宽分成两个方向：

- **上行**：服务器把游戏世界状态、其他玩家的位置和动作、NPC 行为广播给客户端
- **下行**：客户端把自己的操作指令传回来

后者的数据量小得多。一个玩家按键、转向、开火，打包起来可能只有几十字节；但服务器要把同一个画面同步给视野内的所有人。所以规划游戏服务器带宽时，重点盯上行，别被"200M 下行""G 口带宽"这类宣传数字带跑偏。

买机器前先确认一件事：**你看到的带宽数字，是上行还是下行。** 国内不少云服务器默认标注的是下行带宽，而游戏服的压力全在上行那一侧。

## 游戏服务器带宽怎么算：三步估算

通用的估算式大致是这样：

**所需带宽（Mbps）≈ 峰值在线人数 × 单玩家占用（Mbps） × 冗余系数**

三步分别说一下。

### 第一步：取峰值在线人数，不是注册人数

峰值不等于平均。工作日日均 30 人在线的服，周末活动一开可能冲到 90 人。估算时取近一两周的最高在线值，再给推广期留 1.5 倍的想象空间。

### 第二步：查单玩家占用——这一步的区间大得离谱

不同游戏、不同玩法，单玩家带宽消耗能差一两个数量级。下面这些是常见口径，但请注意：**它们来自不同来源，测量条件不一样，只能当起点，不能当结论。**

| 场景 | 单玩家带宽参考 | 说明 |
| --- | --- | --- |
| 我的世界（原版、低视距、少人） | 数十 Kbps 量级 | 有资料按约 0.05Mbps 口径估算 |
| 我的世界（模组服/高视距/高版本） | 0.3–0.5 Mbps | 视距和模组数量会成倍放大 |
| FPS / 竞技类 | 50–400 Kbps | 高频小包，128 tick 更吃网络质量 |
| MOBA | 80–360 Kbps | 中频、同步范围可控 |
| 开放世界生存 / MMO | 80–800 Kbps | 同屏实体多，状态同步量天生大 |
| 幻兽帕鲁 | 约 0.5–1 Mbps | 有资料给出 16 人需 8–16Mbps |
| 方舟：生存进化 | 有服务商按约 2 Mbps/人 估算 | 起步建议 8–12Mbps |

同一款"我的世界"，原版低视距和一个装满两百个模组的整合包，跑出来的数字不是一个世界。官方产品页给的参考基准是：纯净/基岩服视距 6、模组服按 50 个模组视距 5，并且明确提到 1.18+ 的消耗大约是 1.16+ 的两倍、是 1.12.2 的三倍。这个提示很实在——版本本身就在改带宽账单。

### 第三步：乘冗余，别按平均值配

团战、传送、跨地图同步、玩家扎堆在主城，都会让瞬时流量比平时高出一截。游戏场景一般建议预留 30% 以上冗余，活动型玩法按 1.5–2 倍取值。

举个例子：一个模组服，20 人峰值，按 0.3Mbps/人算，加上 1.5 的冗余系数，大约是 9Mbps 上行；如果实际占用偏高，跑到 0.5Mbps/人，就是 15Mbps 上行。10M 和 15M 这两个档位，差距就是这么来的。

## 三个最容易算错的坑

**一是 Mbps 和 MB/s 混着用。** 1MB/s = 8Mbps。有人按"每人每秒传 0.3MB"估算，又直接把结果当成 Mbps 填进购买页，最后差了八倍。

**二是按 100% 利用率算。** 即使是独享带宽，线路损耗和服务器自身处理能力也会吃掉一部分，工程上普遍按 70%–80% 取值，按 75% 更接近实际。

**三是忘了更新流量。** 整合包更新、补丁推送、地图资源下发，任何一个都能在几分钟内把端口打满，游戏逻辑服跟着一起卡。常规做法是把资源下载和游戏逻辑分开，或者把静态资源交给 CDN——但要注意，游戏的实时交互流量本身不适合走 CDN。

## 带宽够 ≠ 不卡：还有三件事在拖后腿

**防御。** 游戏服是 DDoS 攻击的重灾区。一台 20M 带宽的机器，如果遇到 100M 的攻击流量，带宽多大都白搭，机器直接失联。所以选机器时要看清楚共享防御和独享高防分别是什么规格。

**线路质量。** 延迟和丢包对体验的影响往往比带宽数字更直接。玩家集中在华东，机器放华南，多出来的那几十毫秒比你多买 10M 带宽更明显。国内节点就近选，BGP 多线比单线稳。

**磁盘 IOPS。** 这是最容易被漏掉的一项。地图加载和存档落盘都依赖磁盘，IOPS 不够就会周期性掉帧——配置看着够，卡顿却规律出现，多半问题在这里，不在带宽。

## 几个常被问到的问题

**10M 上行能开我的世界服吗？**
能。官方给的参考是纯净服 12+ 人、模组服 6 人。前提是视距别拉到顶，模组别装到失控。如果你的整合包超过两百个模组，10M 那一档基本只够一个人进去逛。

**不限流量是不是就等于带宽随便用？**
不是。游戏云按带宽规格计费、不限流量，意思是这个规格下你可以一直跑满，但跑满也就那么宽。不限流量解决的是"会不会超流量挨罚"，不解决"同时能推多少数据"。

**玩家一多，是升配置还是升带宽？**
先看监控。上行带宽接近峰值、内存和 CPU 都还有空——升带宽。内存先满了、TPS 已经在掉——换更高配置。两个都到顶，那就该考虑多开分区或者换机型了。

**既然算下来 15M 就够，为什么不直接买最贵的求稳？**
因为游戏云支持随时升降级。先用够用的档位跑，压力上来了再升，比一开始就付最贵的月租实际得多——省下的钱够你多买几次流量加购。
